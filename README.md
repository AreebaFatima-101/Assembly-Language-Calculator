# Assembly Language Calculator

An Assembly Language Calculator developed using x86 Assembly Language that performs fundamental arithmetic operations such as addition, subtraction, multiplication, and division. This project demonstrates low-level programming concepts, CPU instruction execution, register manipulation, and user input/output handling.

The calculator provides a simple interface where users can enter numbers and select operations to obtain results. It serves as a practical implementation of Assembly Language programming and computer architecture concepts.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User Input and Output
- Register-Based Calculations
- Error Handling for Invalid Operations

## Technologies Used
- x86 Assembly Language
- MASM / TASM / EMU8086 (depending on implementation)

## Learning Outcomes
- Assembly Language Programming
- CPU Registers and Instructions
- Low-Level Arithmetic Operations
- Memory Management Basics
- Input/Output Handling

This project was developed to strengthen understanding of computer architecture and low-level programming through practical implementation of a calculator application.
